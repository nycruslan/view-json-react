# JsonViewer

A lightweight, read-only tree for safely inspecting JSON and JavaScript values. The v3 viewer combines a bounded iterative data model, WAI-ARIA tree interaction, accurate clipboard results, static CSS, and optional dependency-free windowing.

```tsx
import { JsonViewer } from 'view-json-react';
import 'view-json-react/styles.css';

<JsonViewer data={{ ok: true }} theme="auto" />
```

## Search

Search is controlled by the host application. Matching collapsed descendants are discovered within configured limits, their ancestors are revealed, and F3 / Shift+F3 navigates matches.

## Safe value inspection

The viewer distinguishes non-JSON values rather than rendering blanks or misleading empty objects. Enumerable accessors are described without being invoked, and cycles become references.

<Canvas of={JsonViewerStories.JavaScriptValues} />

## Clipboard and redaction

Clipboard writes are awaited. The `onCopy` callback receives `success`, `error`, `text`, `kind`, the typed path, and the original value. Redaction is applied before copied values are serialized.

## Accessibility

The component follows the WAI-ARIA Tree View pattern:

- `tree`, `treeitem`, and structural ARIA metadata
- managed focus with `aria-activedescendant`
- arrow, Home, End, Page Up, Page Down, Enter, Space, `*`, and type-ahead controls
- accessible copy actions and polite success/failure announcements
- visible focus, coarse-pointer controls, reduced motion, and forced colors

Automated axe checks supplement keyboard and behavior tests; they do not replace manual assistive-technology testing.

## Security and resilience

- No `dangerouslySetInnerHTML`
- No runtime stylesheet injection
- Bounded depth, breadth, visible rows, and search
- Getter-safe property inspection
- Cycle detection and guarded proxy reflection
- Copy-time redaction and safe serialization
- Zero runtime dependencies

The standard viewer is compatible with strict CSP when the static stylesheet is allowed. The virtual entry uses dynamic inline positioning styles.
